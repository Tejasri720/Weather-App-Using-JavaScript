# 🌦️ Weather App

## 📌 About the Project
The Weather App is a simple and responsive web application that allows users to check real-time weather information by entering a city name. It displays temperature, humidity, pressure, and wind speed.

## 🚀 Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Axios
- Font Awesome
- Weather API

## ✨ Features
- Search weather details by city name.
- Display current temperature.
- Show humidity levels.
- Display atmospheric pressure.
- Show wind speed.
- User-friendly interface.
- Responsive design.

## ⚙️ How to Run the Project

1. Clone this repository:
   
   git clone https://github.com/KadavakolluTejasri/Weather-App-Using-JavaScript.git
   

2. Open the project folder.

3. Run `index.html` in your browser.

4. Enter a city name and click the Get Weather button.

## 🎯 Project Objective
The main objective of this project is to understand API integration, Axios, DOM manipulation, and JavaScript event handling while building a practical web application.
